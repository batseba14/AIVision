# AIVision 🤖

AIVision is an Artificial Intelligence platform developed to explore and demonstrate **Machine Learning, Deep Learning, data generation, analytics, and AI application development** using Python and Flask.

The project provides a web-based interface where users can interact with different AI and data-processing features through a centralized application.

## 🚀 Features

### 📊 Analytics Dashboard

* Displays generated and processed data.
* Provides an overview of data patterns and categories.
* Presents information through a web-based dashboard.

### 🧠 Machine Learning

* Supports machine learning functionality using Python and Scikit-learn.
* Provides a dedicated Machine Learning interface.
* Demonstrates the process of working with data and predictive models.

### 🔬 Deep Learning

* Provides a dedicated Deep Learning section.
* Demonstrates neural-network-based AI concepts.
* Uses Python-based machine learning and deep learning technologies.

### 📈 Data Generation

* Generates sample datasets for experimentation.
* Supports different data categories.
* Stores and processes generated data through the application.

### 🖥️ Web Application

* Built using Flask.
* Uses HTML and CSS for the user interface.
* Provides multiple application pages including:

  * Home
  * Dashboard
  * Analytics
  * Machine Learning
  * Deep Learning

## ⚙️ Installation

### 1. Clone the repository

bash
git clone https://github.com/batseba14/AIVision.git


### 2. Navigate into the project

bash
cd AIVision


### 3. Create a virtual environment

Windows:

powershell
python -m venv venv


### 4. Activate the virtual environment
powershell
venv\Scripts\activate


### 5. Install dependencies

install -r requirements.txt


### 6. Run the application

Depending on your project configuration, run:

powershell
python src/backend/app.py


The application should then be available locally through the Flask development server.
